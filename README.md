# Korean Red Root — Landing Page

صفحة هبوط عربية متجاوبة لمنتج **Kwangdong 6 Years Korean Red Ginseng Extract Royal**.

## محتويات المشروع

```text
korean-red-root-landing/
├── index.html
├── styles.css
├── script.js
├── assets/
│   ├── gift-set.png
│   ├── product-details.png
│   └── product-hero.png
├── .gitignore
└── README.md
```

## التشغيل محليًا

لا يحتاج المشروع إلى تثبيت حزم أو أدوات بناء. افتح `index.html` مباشرة في المتصفح، أو استخدم إضافة Live Server في Visual Studio Code.

## الإعدادات المهمة قبل النشر

افتح `script.js` وعدّل القيم داخل `SITE_CONFIG`:

- `whatsappNumber`: رقم واتساب بصيغة دولية، أرقام فقط، بدون `+` أو مسافات.
- `originalPrice`: السعر قبل الخصم.
- `salePrice`: السعر عند الدفع عند الاستلام.
- `digitalPaymentPrice`: السعر بعد خصم الدفع الإلكتروني.

القيم الموجودة حاليًا طبقًا لآخر نسخة من الصفحة:

- السعر قبل الخصم: 8,190 جنيه.
- السعر بعد الخصم: 7,290 جنيه.
- سعر إنستا باي أو المحفظة: 6,561 جنيه.
- رقم واتساب: `201064312414` — راجعه قبل النشر إذا تغير.

## رفع المشروع على GitHub

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **كل محتويات هذا المجلد** مع مجلد `assets`، وليس ملف HTML وحده.
3. من إعدادات المستودع افتح Pages.
4. اختر النشر من فرع `main` ومجلد `/ (root)` ثم احفظ.
5. بعد اكتمال النشر سيظهر رابط الصفحة في إعدادات Pages.

يمكن أيضًا نشر المجلد على Netlify بالسحب والإفلات.

## Meta Pixel

تم إعداد Meta Pixel بالمعرّف `123456789012345` داخل `index.html`، ويرسل حدث `PageView` عند تحميل الصفحة. يرسل `script.js` حدث `Contact` بعد صحة بيانات النموذج مباشرة وقبل فتح رابط واتساب.

بعد النشر، تحقّق من وصول الحدثين باستخدام إضافة Meta Pixel Helper أو أداة اختبار الأحداث في Events Manager. قد يتأخر ظهور الأحداث قليلًا، وقد تمنع أدوات حظر التتبع إرسالها.

## ملاحظات

- الصفحة ثابتة ولا تحتاج إلى قاعدة بيانات أو خادم خلفي.
- نموذج الطلب يجهز رسالة ويرسلها إلى واتساب بعد فتح التطبيق/الموقع؛ لا يحفظ الطلبات في قاعدة بيانات.
- الصور الثلاث الأصلية المرفقة في ملفات المشروع محفوظة داخل `assets`، ولا تعتمد الصفحة على روابط صور خارجية.
